# Komentář k zákonu č. 219/2003 Sb., o uvádění do oběhu osiva a sadby pěstovaných rostlin a o změně některých zákonů (zákon o oběhu osiva a sadby)

Otevřený komentář k zákonu o oběhu osiva a sadby — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; uvádění rozmnožovacího materiálu do oběhu, uznávací řízení, kategorie osiva, dovoz a označování, zvláštní režim, odrůdový řád a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2003-00219_2023-11-01`.
